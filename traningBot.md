# 2. Common Client Questions & Suggested Answers

### Q: Can you build a game?

A: Yes. We build 2D/3D games using Unity, including multiplayer and VR
experiences. Please share your concept and target platform.

### Q: I want to build a chess game.

A: Absolutely. We can build a chess game with features like multiplayer,
AI opponent, leaderboard, and mobile or web deployment.

A: Yes. We use Nakama or Photon for scalable multiplayer infrastructure.

requirements. We typically start with an MVP estimate after
understanding your idea.
